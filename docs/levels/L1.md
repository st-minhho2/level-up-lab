# L1 — Basic setup: "ready on day one"

Goal: a new developer (or a fresh agent session) clones the repo and produces a convention-conforming PR the same
day, because the conventions live next to the code in a form the agent reads automatically.

## Rules

- `CLAUDE.md` holds only what the code cannot say: commands, layout intent, boundaries, session rules. Narrative goes
  in `README.md`; the two never repeat each other.
- Scoped rules in `.claude/rules/*.md` carry `paths:` frontmatter so they load only for matching files, and each
  opens with the mistake it prevents and the section of `nodejs-typescript-coding-conventions.md` it derives from.
- Skills in `.claude/skills/<name>/SKILL.md` have a description that says when to trigger and what they must not do.
- Tool chain is complete from the first commit: lint, format, typecheck, unit, component, e2e, mutation, db scripts.
- Session hygiene: one task per session, `/clear` between tasks, `/compact` at about half context, one approved agent.

## Watch-outs

- `create-next-app`'s generated `eslint.config.mjs` is not type-aware; `next/typescript` alone lets `any` and
  floating promises through. The type-checked config block is the fix, and it needs `projectService: true`.
- pnpm 10 refuses postinstall scripts unless listed in `pnpm.onlyBuiltDependencies`; Prisma, esbuild, sharp and the
  Tailwind oxide binary need it or they silently fail at runtime.
- Vitest 4 warns when the config is `.ts` inside a CommonJS package; `vitest.config.mts` avoids it. The
  `vite-tsconfig-paths` plugin is redundant on Vite 8 (`resolve.tsconfigPaths: true`).
- `next dev --turbopack` and `next build --turbopack` are opt-in on 15.x; scripts never pass the flag, so the same
  webpack pipeline runs locally and in CI.
- `server-only` in `src/lib/prisma.ts` is the only real guard against Prisma in client bundles; ESLint cannot see
  the client/server boundary.

## Metrics

| Type    | Metric                                                       | Target  | How collected                                                            |
| ------- | ------------------------------------------------------------ | ------- | ------------------------------------------------------------------------ |
| Speed   | Time from clone to the first agent-assisted PR for a new dev | ≤ 1 day | Timestamp of first PR opened by a new contributor minus their clone time |
| Quality | Review comments about conventions per PR                     | < 1     | Count review comments tagged `convention` in the PR, averaged per sprint |

## Exit criteria for L1

A fresh session asked to "add an endpoint" reads `CLAUDE.md`, refuses without a spec, and names the three skills it
would use. `pnpm lint && pnpm typecheck && pnpm test && pnpm build` are green on `main`.
