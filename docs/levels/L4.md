# L4 — Isolation: "tasks never collide"

Goal: two tasks (two agents, or an agent and a human) can run `pnpm dev`, `pnpm test:e2e` and `pnpm test:mutation`
at the same time on one machine and never see each other's files, ports, rows, caches or uploads.

## Rules

- One task = one worktree = one branch = one session (`.claude/rules/isolation.md`). The main checkout only holds
  `main`.
- `scripts/worktree.sh <task-name>` is the only way to start a task. It gives the worktree everything stateful:
  port, Postgres schema, build dir, caches, upload dir, cache-key prefix, copied `.env*`, dependencies.
- Code never hard-codes a port, a schema, `.next`, or a storage path; it reads `src/lib/env.ts` or the config
  files, which read `.env` (shell wins over file).
- `scripts/worktree-prune.sh` removes merged worktrees, their branches and their schemas. Worktrees are not reused.

## What the script isolates

| Concern            | Mechanism                                                                     | Read by                       |
| ------------------ | ----------------------------------------------------------------------------- | ----------------------------- |
| Files              | `git worktree add .worktrees/<slug>` (inside the repo root, git-ignored)      | git                           |
| Branch             | `<task-name>` created from `main` (or checked out if it exists)               | git                           |
| Dev / e2e port     | `PORT=3001+cksum(slug)%900`                                                   | `scripts/port.sh`, Playwright |
| Database rows      | `DATABASE_URL=...?schema=wt_<slug>` (search_path on the shared Postgres)      | Prisma, e2e                   |
| Build output       | `NEXT_DIST_DIR=.next` inside the worktree; `outputFileTracingRoot=cwd`        | `next.config.ts`              |
| Test caches        | `VITEST_CACHE_DIR`, `STRYKER_TEMP_DIR` under `<worktree>/.cache`              | `vitest.config.mts`, Stryker  |
| Uploads / storage  | `UPLOAD_DIR=<worktree>/storage/uploads`                                       | `src/lib/env.ts`              |
| Queue / cache keys | `CACHE_PREFIX=wt_<slug>` → `cacheKey(env, 'todos:list')`                      | `src/lib/env.ts`              |
| Secrets            | every git-ignored `.env*` copied from the root, then the keys above rewritten | `.env` in the worktree        |
| Dependencies       | `pnpm install --frozen-lockfile --prefer-offline` from the shared store       | pnpm                          |

## Watch-outs

- **Hidden shared state causes flaky tests.** Two checkouts on the same `public` schema see each other's rows;
  two `next dev` on one port fight; one `.next` written by two builds serves stale chunks; a shared `storage/`
  makes an upload test pass only when run first. Every one of these showed up as "flaky" before it showed up as
  "shared". The table above is the list to check when a test fails only sometimes.
- **Mounting only a worktree folder breaks `.git`.** A worktree's `.git` is a one-line file pointing at
  `<root>/.git/worktrees/<slug>`. A dev container or an editor that mounts `.worktrees/<slug>` alone has no
  repository. Mount the root (see `.devcontainer/`).
- **Worktrees inside the root are visible to every scanner.** Without the ignore entries, `next build`, `tsc`,
  ESLint, Prettier and Vitest would walk `.worktrees/**` and either double-report or crash on a second lockfile.
  Next 15 also "infers the workspace root" from the extra lockfile; `outputFileTracingRoot` pins it.
- **Port 3000 may be taken on a developer machine** (another project's nginx on this one). Override with
  `PORT=3005 pnpm dev`; the shell wins over `.env`.
- **The schema exists only after `db:deploy`.** The script applies migrations if Postgres is up; otherwise the
  first `pnpm db:deploy` inside the worktree creates `wt_<slug>`.
- `scripts/worktree-prune.sh --all` asks on the terminal for unmerged branches; it cannot run unattended.

## Exit criteria for L4

Two worktrees run `pnpm dev` and `pnpm test:e2e` concurrently with no port clash and no cross-schema rows, and
`scripts/worktree-prune.sh` leaves no branch, directory or schema behind.
