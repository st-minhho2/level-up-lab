# scripts — what drives a task, and what CI runs

| Script                                                             | Does                                                                                                                                                                                                                                                                                                       | Needs                                    |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `worktree.sh <branch> [base]`                                      | isolated worktree from a fetched `origin/main` (default base): port, schema, caches, storage, `.env`, deps                                                                                                                                                                                                 | compose PostgreSQL (optional)            |
| `worktree-smoke.sh`                                                | probes K1–K6 of `worktree.sh`'s default base on a throwaway repo (bare origin, `pnpm` shim)                                                                                                                                                                                                                | —                                        |
| `worktree-prune.sh [--dry-run] [--base main] [--all] [--no-fetch]` | removes merged worktrees of every layout (vs fetched `origin/main`), branches, schemas; lists orphans; `--schemas [--drop]`                                                                                                                                                                                | docker; `gh` optional (PR check)         |
| `next-task.sh [--list \| --claim <card> \| --check <card>]`        | next To do card, WIP ≤ 3 Doing; board state from origin/main, branches, PRs; plan overlap                                                                                                                                                                                                                  | `gh` optional (PR states)                |
| `next-task-smoke.sh`                                               | probes W1–W16 of `next-task.sh` on a throwaway repo with a `gh` shim                                                                                                                                                                                                                                       | —                                        |
| `card-status.sh <id> <Open\|Partial\|Done> "<evidence>"`           | rewrites a card's status line                                                                                                                                                                                                                                                                              | —                                        |
| `verify-red.sh <card> [--auto]`                                    | the card's `test(...)` commit fails on behavior at its parent                                                                                                                                                                                                                                              | node_modules; `--auto` PR only in CI     |
| `verify-red-smoke.sh`                                              | probes V1–V14 of `verify-red.sh`'s old-versus-new rule (the base's own run, describe path and title) on plumbing commits in a scratch worktree                                                                                                                                                             | node_modules                             |
| `hook-smoke.sh`                                                    | every hook probe (guards; per worktree layout each role's path-guard and plan-scope S1–S15; check-plan-scope C1–C8; `[ ]` rows L1–L6; dev-lead's review.md block FR1–FR11; dev-lead's `--role` HG1–HG13; gate; role prompts state the Write/Edit rule RP1–RP10; check-ac-coverage titles over lines A1–A8) | node_modules (js-yaml); CI `test`        |
| `prune-smoke.sh [<prune-script>]`                                  | `worktree-prune.sh` probes P1–P15 on a throwaway repo and database (every layout, both checkouts)                                                                                                                                                                                                          | compose PostgreSQL                       |
| `compose-smoke.sh [<compose-file>]`                                | `docker compose` from every checkout layout and the devcontainer overlay reaches `level-up-lab` (C1–C6, read-only)                                                                                                                                                                                         | compose PostgreSQL                       |
| `metrics/lead-time.sh [<card>…]`                                   | approval → feature PR merge per Done card, whole minutes, and the median (`docs/metrics.md`)                                                                                                                                                                                                               | `gh` (auth), fetch of `refs/pull/N/head` |
| `metrics/change-failure-rate.sh [--days 14] [<card>…]`             | fix/revert PRs repairing a merged card within the window ÷ cards                                                                                                                                                                                                                                           | `gh` (auth)                              |
| `metrics/throughput.sh [<card>…]`                                  | cards merged per 8 active hours (D-18), per UTC+7 day                                                                                                                                                                                                                                                      | `gh` (auth), fetch of `refs/pull/N/head` |
| `metrics/wait-time.sh [<card>…]`                                   | plan-gate and PR wait for the lead, medians and the PR upper bound                                                                                                                                                                                                                                         | `gh` (auth), fetch of `refs/pull/N/head` |
| `metrics/plan-deviations.sh [<card>…]`                             | merged card PRs with a file outside the approved plan (a bypass counter since #60)                                                                                                                                                                                                                         | `gh` (auth), fetch of `refs/pull/N/head` |
| `metrics/unattended.sh [<issue>…]`                                 | per `agent-ready` issue: label → ready, lead messages in between, an expected high-tier gate's `approve` excepted; the share (D-29)                                                                                                                                                                        | `gh` (auth)                              |
| `metrics/no-rework.sh [<pr>…]`                                     | per agent PR: commits after ready without `Agent-Run:` and lead comments or reviews after ready; the share (D-29)                                                                                                                                                                                          | `gh` (auth)                              |
| `agent/eligible.sh <issue>`                                        | may the runner take this issue (D-27): the latest `agent-ready` label and the issue's author both have write access; exit 0 or 1 with the reason                                                                                                                                                           | `gh` (auth)                              |
| `agent/eligible-smoke.sh`                                          | probes E1–E9 of `eligible.sh` offline with a `gh` shim                                                                                                                                                                                                                                                     | —                                        |
| `agent/feature-map.sh [--json]`                                    | one row per open `agent-ready` issue with its PR, Evidence and tier (from `tier.sh` on the approved plan, never the body), riskiest first; prints only                                                                                                                                                     | `gh` (auth)                              |
| `agent/feature-map-smoke.sh`                                       | probes F1–F20 of `feature-map.sh` offline with a `gh` shim and a stub tier script                                                                                                                                                                                                                          | —                                        |
| `agent/run.sh <issue> \| --poll \| --check-binary \| --mode`       | dev-lead headless on an `agent-ready` issue (B1.44); `--mode`: `bypassPermissions` only in the runner container (B1.58)                                                                                                                                                                                    | `claude` (lead's login), `gh` (auth)     |
| `agent/sandbox-probe.sh`                                           | probes S1–S7 inside the runner container (`.devcontainer/runner/`): allow list both ways, pin, `--mode`, no caps                                                                                                                                                                                           | the runner container                     |
| `metrics-smoke.sh`                                                 | probes M1–M43 of the metrics scripts on throwaway repos with a `gh` shim                                                                                                                                                                                                                                   | `jq`                                     |
| `pr-step.sh push \| draft "<title>" \| ready <n> [--undo]`         | the card's PR steps (B1.23): push, draft from `backlog/work/<card>/pr-body.md`, ready its own PR; `open` a lane PR from its own body (B1.26); else exit 3                                                                                                                                                  | `gh` (auth)                              |
| `pr-step-smoke.sh`                                                 | probes R1–R15 of `pr-step.sh` on a throwaway repo with a bare origin and a `gh` shim                                                                                                                                                                                                                       | —                                        |
| `require-hooks.sh`                                                 | exit 1 in a Claude Code session that did not load `.claude/settings.json`                                                                                                                                                                                                                                  | Lefthook pre-commit, `worktree.sh`       |
| `install-hooks.sh`                                                 | `prepare`: shared git hooks installed with the main checkout's lefthook binary and this checkout's config                                                                                                                                                                                                  | node_modules (lefthook)                  |
| `githooks-smoke.sh`                                                | probes G1–G9 of the shared hooks (G7–G9: the `Agent-Run:` trailer of a run, B1.57) on a throwaway repo with worktrees and a copied lefthook binary                                                                                                                                                         | node_modules (lefthook)                  |
| `setup-env.sh`, `port.sh`, `load-env.ts`                           | env bootstrap helpers                                                                                                                                                                                                                                                                                      | —                                        |
| `ci/check-suppressions.sh`                                         | no new `eslint-disable` / `@ts-*`                                                                                                                                                                                                                                                                          | git range                                |
| `ci/check-config-change.sh`                                        | protected config needs the label                                                                                                                                                                                                                                                                           | git range; PR only in CI                 |
| `ci/check-feat-commits.sh`                                         | `feat(` commits touch no test                                                                                                                                                                                                                                                                              | git range; PR only in CI                 |
| `ci/check-ac-coverage.sh`                                          | every `AC-§.n` of a ✅/◐ section is a test title                                                                                                                                                                                                                                                           | —                                        |
| `ci/check-spec-sections.sh`                                        | every `§n` cited in `src/`, the map and cards exists                                                                                                                                                                                                                                                       | —                                        |
| `ci/check-features-map.sh`                                         | every path and section in the map resolves                                                                                                                                                                                                                                                                 | —                                        |
| `ci/check-backlog.sh`                                              | README totals equal card status lines; remaining rows are Open/Partial cards                                                                                                                                                                                                                               | —                                        |
| `ci/check-agent-frontmatter.sh`                                    | agent/skill frontmatter is YAML with `name`, `description` (`--commands`)                                                                                                                                                                                                                                  | node_modules (js-yaml)                   |
| `ci/plan-files.sh [--any] <card> [<rev>]`                          | the Files of a card's plan as of its approval commit (exit 3 unapproved, 4 no plan); `--any`: at `<rev>`, approved or not                                                                                                                                                                                  | git; run in the card's worktree          |
| `ci/check-plan-scope.sh`                                           | a card branch's diff (from merge-base with `origin/<base>`) stays inside its approved plan; paperwork passes                                                                                                                                                                                               | git range; `GITHUB_HEAD_REF` in CI       |

All scripts are bash 3.2-safe (macOS) and run unchanged in the dev container and CI. No script is paid or
destructive; none touches a non-local database.
